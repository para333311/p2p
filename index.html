소스 코드 버전 실행 방법

이 버전은 CMD/PowerShell 실행 파일을 포함하지 않습니다. 먼저 공식 Python 3.13.12 (64비트)를 설치하세요.

  1. ZIP 압축을 풀어 launch.py가 있는 폴더를 여세요.
  2. 폴더 빈 곳을 마우스 오른쪽 버튼으로 눌러 터미널에서 열기를 선택하세요.
  3. py -3.13 launch.py를 입력하고 Enter를 누르세요.

최초 실행에는 인터넷 연결이 필요합니다. 이 HTML 파일을 직접 열면 안내만 볼 수 있습니다. 로그인 및 다운로드 제어판은 위 명령으로 실행했을 때 자동으로 열립니다.

스마트 앱 컨트롤 호환성을 보장하는 서명된 앱은 아닙니다. 다른 파일이 차단되면 보안 설정을 유지하고 차단된 파일명을 확인하세요. 차단 해제·이름 변경·보호 기능 중지를 시도하지 않습니다.

이미 이전 버전을 사용했다면 작업을 종료하고, 기존 data 폴더를 보존하세요. 기존 다운로드 이력을 새 버전에서도 유지해야 중복 요청을 막을 수 있습니다.

처음 한 번 로그인하고 폴더를 확인하면, 선택한 영화의 검색과 다운로드 요청을 순서대로 진행합니다.
화면에서 다운로드 정액권 적용이 확인되는 비제휴 파일만 요청합니다. 확인창은 자동 취소하며, 알 수 없는 상태에서는 멈춥니다.
1

피디팝 로그인

아래 버튼으로 열린 별도 Edge 창에서 직접 로그인하세요. 비밀번호를 도우미에 입력하거나 보내지 않습니다.

평소 쓰던 Edge와 다른 전용 프로필입니다. 전용 다운로더도 실행해 두세요. Edge가 로컬 네트워크 접근 허용을 물으면 피디팝에만 허용하세요.

2

저장 폴더 확인

자동 인식이 안 되면 전용 다운로더의 저장경로변경에서 이 폴더를 지정하세요. 이 입력칸만 바꾸면 다운로더 설정이 바뀌는 것은 아닙니다.

3. 영화 선택

원개봉 연도가 1990~1999년인 기본 목록을 불러오는 중입니다.

전체 1990년대 영화 데이터베이스가 아닌 기본 60편 목록입니다. 게시물 제목에 영화명과 정확한 개봉 연도가 함께 있는 경우만 선택합니다. 잘못 표기된 제목까지 완벽히 식별하지는 못하며, 리메이크·합본·중복·불명확한 결과는 보수적으로 제외합니다.

연결 중제어판에 연결하고 있습니다.

최대 편수는 이번 실행에서 처리하는 편수입니다. 한 게시물에 영상 1개와 자막만 선택하고 스크린샷·실행파일은 제외합니다. 편당 12GB 이하, 다운로드 후 여유 공간 5GB 이상. 다음 영화는 앞 영화의 저장 파일 확인 후 시작합니다.

이전 요청 이력 · 중복 방지

요청 직전에 이력을 저장합니다. 멈추거나 재실행하더라도 전송 여부가 불확실한 영화를 자동으로 다시 요청하지 않습니다. 필요한 경우 전용 다운로더의 대기열과 폴더를 직접 확인한 후 해당 이력만 해제하세요.

사용 안내 · 문제 해결 · 검증 범위
  • 윈도우 10/11 64비트, Microsoft Edge, 공식 피디팝 전용 다운로더가 필요합니다. 도우미는 피디팝 공식 제품이 아닙니다. 계정·이용권은 제공하지 않습니다.
  • 로그인과 세션은 이 프로그램 폴더의 data/edge-profile에만 저장됩니다. 이 폴더를 다른 사람에게 보내지 마세요. 이력은 data/history.json에 저장됩니다. 분석 서버나 외부 AI로 로그인 정보를 보내지 않습니다.
  • 현재 공개 사이트 구조를 조사해 구현했습니다. 로그인된 실제 회원 계정 및 윈도우 전용 다운로더를 이용한 끝까지의 다운로드는 개발 환경에서 검증하지 못했습니다. 첫 실행은 1편으로 시험하는 것을 권장합니다.
  • 사이트의 정액권 플래그와 제휴 여부를 읽고 공식 다운로드 버튼만 누릅니다. 사이트 자체의 권한·결제 검사를 우회하지 않습니다. 과금 정책과 서버 처리는 사이트가 결정하므로 과금이 절대 없음을 보증하지는 않습니다. 예상치 못한 확인창은 자동 취소하고 중지합니다.
  • 설치 안내가 나오거나 요청을 확인하지 못하면 공식 다운로더 실행 상태, Edge의 피디팝 로컬 네트워크 권한을 확인하세요. 사이트 구조가 바뀌면 동작을 멈추도록 되어 있습니다.
  • ‘요청’은 완료가 아닙니다. 파일 확인은 파일명·정확한 바이트 크기·윈도우 파일 잠금 해제를 반복 확인한 결과이며, 영상 재생이나 해시 무결성 검증이 아닙니다. 기존 파일도 이름과 크기로만 판별합니다.
  • 대기열 중지나 프로그램 종료는 이미 전용 다운로더로 넘어간 전송을 취소하지 않습니다. 진행 중인 전송은 전용 다운로더에서 일시정지/취소하세요. 다운로드 도중 저장경로·선택파일·브라우저 탭을 변경하지 마세요.
  • 기본 목록에 없는 작품 추가, 여러 동영상으로 나뉜 게시물, 연도가 없는 제목, 자동 CAPTCHA 처리, 쿠폰 사용, 유료 제휴 콘텐츠, 성인인증 우회는 지원하지 않습니다.
  • 저장 폴더 자동 설정은 표준 접근성 버튼과 폴더 대화상자를 찾았을 때만 시도합니다. 사용자 PC에서 버튼이 보이지 않으면 수동으로 한 번 지정해야 합니다.
  • 공식 Python 3.13.12 이상 3.13.x 일반 64비트 버전을 먼저 설치한 뒤, 이 폴더의 터미널에서 py -3.13 launch.py를 실행하세요. 최초 실행 시 PyPI에서 해시 검증한 의존성을 전용 가상환경에 설치합니다. CMD/PowerShell 실행 파일, 관리자 권한, 보안 설정 변경은 사용하지 않습니다. 최신 3.14나 자유 스레딩 버전은 이 패키지의 지원 대상이 아닙니다.
  • 공식 Python을 사용하는 소스 코드 실행 방식이며, 스마트 앱 컨트롤이 검증한 서명 앱이라는 의미는 아닙니다. Python, Playwright의 node.exe 또는 다른 구성요소가 차단되면 중지하고 해당 파일명을 확인하세요. 보호 기능을 끄거나 파일의 보안 표시를 지우지 마세요.
창만 닫아도 프로그램은 계속 실행됩니다. 종료 버튼 또는 실행창에서 Ctrl+C를 누르세요.

개인 이용을 위한 보조 도구입니다. 다운로드 권한이 있는 콘텐츠에 한해 사이트 약관과 이용권 범위 안에서 사용하세요.
